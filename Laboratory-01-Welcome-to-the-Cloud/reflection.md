reflection

Through this onboarding mission, I gained practical hands-on experience navigating a Linux cloud environment using KillerCoda. I learned essential administration commands like creating non-root users, managing permissions with `sudo`, inspecting hardware/OS specs, and organizing workspace files using Markdown and Git.

Working strictly through the command-line interface required paying close attention to syntax, file paths, and proper directory structures. Managing files and committing screenshots directly through GitHub also reinforced the importance of structured version control.

I aim to build upon these foundations to master containerization (Docker), orchestration (Kubernetes), and cloud deployment automation as I progress through the CCM101 course.
