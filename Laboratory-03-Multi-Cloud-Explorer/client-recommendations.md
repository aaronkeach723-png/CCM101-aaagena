# Cloud Platform Recommendations

## Client Scenarios and Recommendations

### Client A – Startup Company
* **Recommended Cloud Platform:** Amazon Web Services (AWS)
* **Explanation:** AWS is the best choice for startups because it offers strong growth tools, high flexibility, and flexible pay-as-you-go pricing. It allows startups to launch quickly with minimal upfront costs while easily scaling up as user numbers increase. The platform also provides massive community support and startup credits to manage initial expenses.
* **Suggested Services:**
  - Amazon EC2 (for running application servers)
  - Amazon S3 (for storing app files and media)
  - Amazon DynamoDB (for scalable application databases)

---

### Client B – University
* **Recommended Cloud Platform:** Microsoft Azure
* **Explanation:** Microsoft Azure is the ideal choice for this university because of its native integration with existing systems like Active Directory, Windows Server, and Microsoft 365. Migrating to Azure requires minimal retraining for staff because it uses the exact same security policies and user accounts already in place. The university can also save money using existing Microsoft software licenses.
* **Suggested Services:**
  - Azure Virtual Machines (for hosting university apps)
  - Microsoft Entra ID / Azure AD (for user identity management)
  - Azure Blob Storage (for student records and backups)

---

### Client C – AI Research Company
* **Recommended Cloud Platform:** Google Cloud Platform (GCP)
* **Explanation:** Google Cloud Platform is built for heavy data processing, Artificial Intelligence, and Machine Learning workloads. GCP provides industry-leading AI tools and ultra-fast hardware designed specifically for deep learning research. It allows researchers to train complex machine learning models quickly and analyze huge amounts of data efficiently.
* **Suggested Services:**
  - Google Compute Engine with GPUs/TPUs (for high-performance computing)
  - Vertex AI (for building and training AI models)
  - BigQuery (for fast big data analytics)

---

### Client D – Global E-Commerce Company
* **Recommended Cloud Platform:** Amazon Web Services (AWS)
* **Explanation:** AWS has the largest and most proven global network, making it perfect for a multinational shopping site that needs fast response times everywhere. It handles traffic spikes automatically during major sales events without crashing. Its global footprint ensures that international customers always experience high speed and secure access.
* **Suggested Services:**
  - Amazon EC2 with Auto Scaling (for handling website traffic spikes)
  - Amazon CloudFront (for fast global content delivery)
  - Amazon Aurora (for high-speed, reliable shopping databases)

---

## Multi-Cloud Decision Matrix (Checkpoint 6)

| Business Requirement | Recommended Platform | Justification |
| :--- | :--- | :--- |
| **Startup Company** | **AWS** | Flexible pay-as-you-go pricing and great startup support for fast scaling. |
| **Enterprise Organization** | **Microsoft Azure** | Strong enterprise security, hybrid options, and easy system migration. |
| **Microsoft Environment** | **Microsoft Azure** | Direct connection with Windows Server, Active Directory, and Office 365. |
| **AI / Machine Learning** | **Google Cloud Platform** | Industry-leading AI platforms, fast hardware, and top data engines. |
| **Kubernetes Deployment** | **Google Cloud Platform** | Best container support because Google built and created Kubernetes. |
| **Global Web Application** | **AWS** | Largest worldwide network with auto-scaling to prevent crashes. |
