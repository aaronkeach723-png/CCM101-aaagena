Among the three public cloud platforms I evaluated, Google Cloud Platform (GCP) impressed me the most. Its infrastructure focuses on modern applications, containerized systems, and artificial intelligence. Since Google created Kubernetes and provides machine learning tools like Vertex AI, GCP shows strong innovation and good cloud performance. I also find GCP interesting because it provides useful tools for developers and businesses that want to use modern cloud technologies.

Although AWS, Microsoft Azure, and GCP have different product names and user interfaces, they have many of the same basic features. All three provide important IaaS services such as virtual machines, object storage, private networks, and Identity and Access Management (IAM). They also have data centers around the world that are divided into regions and availability zones. These help keep services available, reduce the effect of system failures, and support disaster recovery.

Choosing a cloud provider depends on the needs of a business rather than popularity. Companies need to consider their budget, existing software, technical skills, security needs, and future growth. For example, businesses that already use Windows Server and Active Directory may prefer Azure because it works well with Microsoft products. Startups may choose AWS because it offers many services and flexible payment options.

Being a Cloud Solution students, it taught me that cloud engineering is not only about choosing technology. It is also about finding solutions that match the goals of a business. Cloud decisions should consider cost, performance, security, and scalability. Completing this mission improved my GitHub Cloud Computing Portfolio by helping me organize cloud information, compare different platforms, study real-world situations, and understand basic cloud migration through the terminal.
