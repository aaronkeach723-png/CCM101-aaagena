Amazon Web Services (AWS) Research Report

Brief Overview
Amazon Web Services (AWS) is a known cloud computing platform provided and developed by Amazon. It is launched publicly in 2006, AWS is the considered as the pioneer of modern cloud infrastructure, offering over 200 fully featured services from data centers globally.

Global Infrastructure
AWS operates in multiple geographic regions worldwide. Each AWS Region consists of multiple isolated and physically separated Availability Zones (AZs) connected through low-latency, high-throughput, and highly redundant networking.

Cloud Management Console
The AWS Management Console is a web-based portal that allows users to access and manage their cloud resources, monitor billings, configure security, and manage permissions across services.

Core Services
• Amazon EC2 (Elastic Compute Cloud): Provides resizable compute capacity in the cloud as virtual servers.
• Amazon S3 (Simple Storage Service): Scalable object storage designed for high durability and data availability.
• Amazon VPC (Virtual Private Cloud): Allows users to provision a logically isolated section of the AWS Cloud.
• AWS IAM (Identity and Access Management): Controls user authentication and resource access permissions securely.

Advantages
• Market Maturity: have the widest range of mature cloud services and extensive community support.
• Global Reach: Extensive network of global data centers and edge locations.
• Scalability: High flexibility to scale resources up or down rapidly based on demand.

Typical Enterprise Use Cases
• Large-scale global web application hosting.
• Enterprise data archiving and disaster recovery solutions.
• Microservices architectures and serverless backend deployments.
